# 研究所需技能学习路径（代码小白版）

> 目标：让你从"能跑别人/我写好的脚本"成长到"能自己读论文代码、改、跑实验、写自己的方法"。
> 原则：**研究导向**，不是软件工程导向——你要的是"看懂并改得动"，不是"写产品"。

---

## 〇、先读这三条原则

1. **边做边学（just-in-time）**：不要先学完再开始。每个阶段只学"刚好够做下一步"的量，然后立刻在你自己的数据上练。学 100 小时抽象理论，不如 10 小时学 + 90 小时在你自己的 PathoGaze CSV / PathAgent 代码上动手。
2. **你的数据就是教材**：`D:\pathologyData\PathoGaze1.0` 的 CSV、`D:\PathCode` 的 PathAgent 代码，比任何教程都更贴合你的研究。所有练习尽量在上面做。
3. **两个层次，诚实预期**：
   - **生存层（Level A）**：能跑、能改参数、能看懂报错、能在 AI 助手（我）配合下 debug —— 每天 1–2 小时，**约 3–6 个月**可达。
   - **独立层（Level B）**：能自己设计方法、写论文实验、不靠人带 —— 通常 **1–2 年**。研究期间你只需要先到 A，再往 B 长。

## 一、技能地图：你的研究环节 ↔ 需要的技能

| 研究环节 | 需要的技能 | 难度 | 优先级 |
|---|---|---|---|
| 读数据（GazeOnlyData.csv 等） | Python + **pandas** | ★★ | 🔥最高（几乎天天用） |
| 坐标变换/轨迹精简 | **numpy** 数组运算 | ★★ | 🔥最高 |
| 画低倍图 + 轨迹（框/箭头） | **matplotlib** | ★★ | 🔥最高 |
| WSI 读取/切块/降采样 | **OpenSlide** + PIL | ★★★ | 高 |
| 提取特征/跑模型推理 | **PyTorch** + HuggingFace **transformers** | ★★★★ | 高 |
| 多模态/Agent（Navigator/Perceptor/Executor） | CLIP/PLIP、Qwen-VL、LLM 推理、量化 | ★★★★ | 中（你已有现成代码可对照学） |
| 轨迹对比（Agent vs 专家） | 度量算法（MultiMatch/ScanMatch） | ★★★ | 中 |
| 复现与版本管理 | **git** + 虚拟环境 + 实验记录 | ★★ | 中 |
| 读懂论文方法 | 数学基础（线性代数/概率的"够用"部分） | ★★★ | 中 |

> 结论：**Python + numpy + pandas + matplotlib 是地基，必须先打牢**。它们占你日常工作的 70% 以上（数据处理、分析、画图）。

## 二、分阶段学习路径

### Phase 0 · Python 语法基础（2–3 周）
- 学：变量、类型（int/str/list/dict）、循环、函数、`import`、读文件、`if/else`。
- 为什么：后面一切都基于此。
- 资源：廖雪峰《Python 教程》（免费中文）或《Python 编程：从入门到实践》前 10 章。
- 验收：能独立写一个脚本，读取一个 CSV 并打印前 5 行；能用 `dict` 存映射关系（比如 C1↔test_001）。

### Phase 1 · numpy + pandas + matplotlib（3–4 周）★最关键
- 学：
  - numpy：数组、切片、`np.where`、广播、`np.linalg.norm`（轨迹距离/角度都要用它）。
  - pandas：`read_csv`、`df[df["inImage"]==True]` 过滤、`groupby`、`merge`、`value_counts`、时间排序。
  - matplotlib：`plot`/`scatter`/`imshow`/`Rectangle`/`annotate`（画箭头）。
- 为什么：你的眼动数据全是 CSV，轨迹精简/可视化全在这三者上。
- 资源：《Python 数据科学手册》（Jake VanderPlas，**有免费中文版**）第 2/3/4 章，覆盖这三样。
- 验收（直接绑研究）：**独立完成我在 `verify_gaze_feasibility.py` 里做过的事**——读出 C48 的图内注视点，按 `GazeEventDuration` 阈值过滤，打印每个阈值剩余点数，并用 scatter 把注视点画出来。

### Phase 2 · PyTorch 基础 + transformers 推理（3–4 周）
- 学：张量（tensor）、`torch.no_grad()`、模型 = 一堆权重、`from_pretrained` 加载、前向推理、`device`(GPU/CPU)、`.numpy()`。
- 为什么：PathAgent 的 Navigator/Perceptor/Executor 全是 PyTorch 模型；你至少要懂"加载→喂数据→拿输出"。
- 资源：PyTorch 官方《60 分钟入门》；HuggingFace **transformers 文档的 quick tour**（`AutoModel`/`AutoTokenizer`/`from_pretrained` 三件事）。
- 验收：能加载一个本地 PLIP/CLIP 模型，把一张图编码成 512 维向量并打印前 5 个数（对照 `compute_plip_features.py`）。

### Phase 3 · 计算机视觉 + WSI 处理（2–3 周）
- 学：图像=H×W×3 数组、PIL 读图/裁剪/resize、**OpenSlide**（金字塔、level、`get_thumbnail` 降采样、`read_region`）。
- 为什么：要做低倍概览图、切 patch、坐标↔底图映射。
- 资源：openslide-python 官方文档的 `get_thumbnail`/`read_region` 示例；`histolab` 的 tile 示例。
- 验收：用 OpenSlide 打开一张 WSI（或先用掩膜 TIF 顶替），生成一张 2048px 宽的缩略图。

### Phase 4 · 多模态 / LLM / Agent（4–6 周，边做边学）
- 学：CLIP 双塔（文本/图像编码 + 余弦相似度）、VLM（图像+文本进一个模型）、chat template、生成参数、**4-bit 量化**（bitsandbytes）。
- 为什么：这是你的方法核心——PathAgent 的 Navigator 相似度检索、Perceptor 描述、Executor 决策。
- 资源：读 **你手上的 `D:\PathCode\pathagent.py` 和 `models\inference.py`**（逐行对照我之前的讲解）；CLIP 论文概念；Qwen2.5-VL 文档。
- 验收：能口述 PathAgent 主循环每一步"输入是什么、输出是什么、用哪个模型"，并能改 `initial_sample_ratio` 等参数后重跑。

### Phase 5 · 眼动/轨迹分析（贯穿，核心是练手）
- 学：注视点过滤、坐标变换（屏幕↔图像）、轨迹精简算法（**Chakraborty Algorithm 1**：角度/时长/距离/倍率四规则）、轨迹对比度量（MultiMatch/ScanMatch）。
- 为什么：这就是你第二阶段+第三阶段的目标本身。
- 资源：`轨迹精简_相关文献调研.md` 里列的两篇 Chakraborty 论文；MultiMatch 原论文。
- 验收：把 Chakraborty Algorithm 1 翻译成 Python，在 C48 上把 1000+ 点精简到几十个点，并画"原始 vs 精简"对比图。

### Phase 6 · 工具与复现（随时，碎片时间）
- 学：git（clone/commit/分支）、venv/conda 环境、Jupyter Notebook、实验日志记录。
- 为什么：你导师强调证据链可追溯，复现和版本管理是硬要求。
- 资源：廖雪峰《Git 教程》前 3 讲；你的 `下载总结.md` 本身就是"实验记录"范本。

## 四、最小可行 vs 完整路径（诚实的时间预期）

- **最小可行（先做这个）**：Phase 0 → 1 → 2（只学"加载+推理"，不学训练）→ 3（只学 OpenSlide 三个 API）→ 直接用现成代码做 Phase 5 的练手。
  - 理由：你是**研究者**，不是算法工程师；训练、调参、写复杂网络可以后期再补，前期"会用现成模型"就够支撑实验。
- **完整路径**：再加上训练基础（损失函数、优化器、训练循环，用《动手学深度学习》）、以及扎实的线代/概率。
  - 理由：如果你后面要**改模型结构**或**训自己的预测器**（比如 Behavior-Predictor 那种），才需要这些。
