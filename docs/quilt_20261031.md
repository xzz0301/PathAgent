# Quilt 独立环境与真实图块验收（2026-10-31）

## 为什么需要独立环境

Quilt-LLaVA 为图块生成离线通用描述；Patho-R1 在 Agent 运行时生成问题相关描述。
权重已存在不代表这两条流程都已跑通。此前 C1 使用 64 个真实图块，但通用描述为空，
并显式开启 `--allow-empty-descriptions`；这是连通性测试，不是完整预处理验收。

Quilt 固定源码依赖旧 Transformers API，主 Agent 使用 Transformers 4.51.3。
直接在主环境降级会影响 Qwen3 / Patho-R1。因此创建独立 venv，局部安装旧 API 包，
通过 `.pth` 只读复用主环境的 CUDA 库。该环境依赖主环境仍存在，并非完全独立可搬移的镜像。
未来升级主环境后应重新验收或重建 Quilt 环境。

## 真实图块验证

`tools/quilt_acceptance.py` 直接调用项目的 `data_preparation_script/description_generation.py`，
记录该脚本与输入图块的 SHA256、实际模型类、量化方式、GPU、版本和输出覆盖率。
采用原流程的 NF4 量化、temperature=0.2、seed=128，明确 `pathology_v0`。
输出目录必须不存在，历史失败与结果不覆盖。

```bash
R=/data/dataset/users/xuzhaozheng/pathagent
CUDA_VISIBLE_DEVICES=0 "$R/envs/quilt_20261031/run_quilt.sh" tools/quilt_acceptance.py \
  --project-root "$R/code/current" \
  --patch-root "$R/code/current/demo/c1_independent/patches" \
  --slide-id DX1_C1 \
  --model-path "$R/models_runtime/Quilt-Llava-v1.5-7b-local_20261031" \
  --output-dir "$R/artifacts/quilt_c1_new_run" \
  --sample-count 0 --max-new-tokens 512 --load-4bit
```

`--sample-count 2` 用排序后均匀抽取的两个图块做小样本验证；`0` 使用全部候选图块。
这些检查确认加载、真实图像输入和描述文件完整性，不证明描述的病理准确率。
