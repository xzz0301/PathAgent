## 6. 迁移到新服务器

迁移同一项目的源码和必要的 `external/PLIP`，不要复制 Windows `.venv310` 到 Linux。模型只需复制 `Qwen3-4B`、`plip`、`Patho-R1-7B` 三个目录；旧 3B 权重留在本地即可。切片、patch、PLIP 特征、通用描述和几何文件应配套传输。

新服务器先记录：`nvidia-smi`、驱动版本、`torch.__version__`、`torch.version.cuda`、`torch.cuda.get_device_capability(i)`、`torch.cuda.is_bf16_supported()`。根据实测驱动与 GPU 选择兼容的 PyTorch CUDA 构建。本地验证环境为 PyTorch 2.7.0+cu128、Transformers 4.51.0；本次未改依赖版本，也未连接旧服务器或上传数据。

在项目根目录执行原模型的 C1 **文件检查**：

```bash
python pathagent.py --config configs/server_original.json \
  --descriptions_file demo/c1_independent/descriptions.json \
  --questions_file demo/c1_independent/questions.json \
  --feature_dir demo/c1_independent/features \
  --patch_root demo/c1_independent/patches \
  --geometry_file demo/c1_independent/geometry.json \
  --save_dir outputs/c1_server_smoke \
  --allow-empty-descriptions --check-inputs
```

此命令不分配模型到 GPU。输入检查通过后，去掉 `--check-inputs` 即运行同一套主程序；需要限定测试预算时追加 `--initial_sample_count 5 --max_attempts 3 --perceptor_max_new_tokens 512`。可用 `--patho_r1_ckpt /实际路径/Patho-R1-7B` 覆盖模型路径。

当前 C1 的 64 个通用描述都是空字符串，所以示例明确加上 `--allow-empty-descriptions`，只用于连通性测试。正式输入补齐 Quilt-LLaVA 描述后，去掉该开关。服务器配置默认拒绝空描述，避免把未完成的输入当成原版实验。

当前放大逻辑仍是裁剪已有 patch，没有读取 WSI 的更高分辨率层。运行元数据明确记录 `zoom_source=crop_existing_patch_not_higher_resolution_wsi`。后续研究若需真实多尺度证据，应单独设计 WSI 重读，不能将当前裁剪解释为新增高分辨率证据。

新服务器验收还需做：三模型实际 BF16 加载、C1 导航与导出、设备映射及显存记录、终止条件检查。实际服务器运行结果不包含在本次本地验证结论内。
