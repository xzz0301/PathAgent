# 原始WSI读取、PEAN规则对齐与六例分类验证

本页覆盖旧首轮文档中“WSI读取待实施”和PEAN旧独立适配器的说明。唯一源码为D:/PathCode；计算在6000D的code/current进行。当前六例推理仍在运行准备阶段，不能将测试通过或准备完成写成诊断准确率。

## 1. Agent观察到什么

Patho-R1-7B承担观察，Qwen3-4B承担执行与最终作答，PLIP承担导航检索。Quilt-LLaVA生成候选区域的通用描述，沿用原有NF4设置；Patho-R1与Qwen3使用BF16。正式导航展示不使用独立Qwen2.5-VL定位候选。

新增`--image-backend wsi --wsi-manifest <文件>`。每次观察由候选坐标或导航选择产生level-0矩形，在原始WSI金字塔中选取不粗于目标分辨率的层读取。记录实际读取层、downsample、读取尺寸、输出尺寸、MPP、WSI身份和输入图像SHA。放大读取相同组织范围内更细的像素，不再仅放大旧patch。越界、错误切片或缺失几何均报错，不静默退回裁剪。

导航候选几何与检索策略保持原有逻辑；高分辨率像素改变后，模型描述和候选排名可能改变。主图显示实际ROI框、倍率和访问箭头。ROI中心仅用于几何记账/连接，不解释为模型精确注视位置。定位提议另外保存；格式正确不代表形态位置正确，不补中心点。

C1先用原来的4个固定ROI作成对回放：相同Patho-R1、问题、随机种子，分别输入旧像素与原WSI新读像素，记录处理器网格与描述。回放本身不重新产生整片诊断。之后独立运行六例完整导航和最终分类。

## 2. PEAN如何沿用原有规则

原PathoGaze最终观察规则和几何压缩代码已提取到`experts/observations.py`和`experts/compression.py`，来源与SHA见`experts/rule_provenance.json`。除了通用时间轴字段命名与导入调整，核心规则未另造一套。冻结原算法输出的回归测试用于核对一致性。

处理链：EPR与WSI身份匹配 → 逐帧屏幕坐标投影到WSI level-0 → 无效/越界/背景筛除 → 固定首点锚点、细览窗口与连续缩放归并 → 回访识别 → 有效支持资格 → 几何压缩 → 最终连续编号 → 全片箭头与右侧访问表。

固定区域半径为level-0的横向1500px、纵向2600px；细览判断短边35000px；同窗口IoU 0.65，回访0.75；连续缩放嵌套覆盖0.85，倍率相对差容忍0.02。参数为复用基线，不代表已验证适合所有PEAN扫描倍率或疾病。

| PathoGaze处理所需信息 | PEAN实际可用内容 | 本轮做法及缺口补救 |
|---|---|---|
| WSI身份和尺寸 | EPR内部quickHash及对应NDPI | 校验身份、尺寸及金字塔后投影；不按文件名猜配 |
| 眼动图像坐标 | 原屏幕落点、屏幕大小、浏览中心及层级 | 按格式定义投影，保留原值、投影值与剔除原因；真实应用内容边界仍需原视频/软件核验 |
| 实测fixation起止时间 | 原timestamp与头部50FPS，但单位关系未核实 | 主版只用帧序；另列50FPS估计150ms敏感性版。向作者核实单位/采样机制，有同步视频后再校准 |
| inImage、置信度、固定注视区间 | 缺少等价原生字段 | 几何边界及组织掩膜作替代QC，明确不能替代眼动仪置信度和校准误差 |
| 鼠标框选/填写操作时序 | 90份唯一EPR均无MAPDATA/THRESHOLD段 | 不制造鼠标事件、不标红；需补原事件日志或对同步视频作可追溯事件标注 |
| 标注或诊断信息 | NDPA静态几何、TAIL病例级类型/少量comment | 单独导出；不能从静态标注推断绘制时间或把病理标签当注视证据 |
| 医生身份与独立样本数 | 150份文件只有90份不同EPR内容，身份字段脱敏 | 按内容去重并保留记录ID；不声称150位独立专家或150条独立记录 |

主版的`valid_support_ms`为空；估计版也保持实测列为空，仅`estimated_support_ms`存估值。有效帧只支持下一帧间隔，最后一帧不凭空增加时长。无效帧不贡献时间，也不机械切断同一次观察。不同回访的时间不拼接来凑阈值。

| 案例 | 旧访问数 | 原规则空间版区域/访问 | 50FPS估计150ms版区域/访问 |
|---|---:|---:|---:|
| BCC 59979 | 43 | 3 / 5 | 2 / 3 |
| SCC 59988 | 112 | 8 / 19 | 8 / 17 |
| melanoma 62403 | 93 | 6 / 17 | 7 / 12 |

数量减少反映算法对齐，尚不等于更真实。两个输出不能直接当作两个实测时长条件；估计版过滤改变后续压缩几何，区域数不必单调。`regions/steps/edges`使用最终展示编号，events及审计保留原编号并提供`display_*`映射。静态NDPA线条条目不等于独立鼠标操作次数。

## 3. CAMELYON16六例开发性验证

| 病例 | 官方WSI | 标签 | 官方病灶类型 |
|---|---|---|---|
| C1 | test_001 | Malignant | macro |
| C2 | test_008 | Malignant | micro |
| C48 | test_029 | Malignant | micro |
| C6 | test_036 | Benign | negative |
| C8 | test_045 | Benign | negative |
| C12 | test_053 | Benign | negative |

病例集合与参数在推理前固定。C1复用原64候选；其余在组织覆盖≥0.25的网格候选中按行序等间隔选64个。选择不使用专家落点或病灶标注。原图候选为2048×2048 level-0范围、512px@名义10x，初始观察3个，最多5轮，seed128。没有覆盖完整切片，尤其可能遗漏微转移；此试验评估这套受限候选导航流程，不能代表全片诊断系统总体性能。

推理问题的Answer统一为WITHHELD。官方reference仅在输出后由评价脚本合并。报告逐例结果、TP/TN/FP/FN、无效输出、accuracy及Wilson95%区间、敏感度、特异度、balanced accuracy，并单列排除既有C1后的5例正确数。无效/缺失输出保留在分母中。不提供没有连续可靠分数支持的AUROC。

目前已有旧C1裁剪基线预测Malignant，与官方标签一致。六例新WSI模式结果以实际`metrics.json`为准，不能从单例正确推断100%准确率。

## 4. 可复核产物

- `tools/run_camelyon_preparation.py`：冻结候选、原Quilt描述和PLIP特征准备。
- `tools/run_camelyon_validation.py`：等待准备完成，再做C1成对回放和六例导航分类，最后评价与绘图。已有输出拒绝重复覆盖。
- `tools/evaluate_camelyon_pilot.py`：官方标签合并、逐例CSV、指标JSON与ROI展示入口。
- `tests/test_wsi_regions.py`：真实高分辨率读取、身份/越界与逐次ROI。
- `tests/test_shared_gaze_rules.py`：原规则输出一致性、无效间断、单帧时长、连续编号。
- `tests/test_camelyon_evaluation.py`：无效和缺失预测仍保留六例分母。

PEAN三例和CAMELYON16六例来自不同切片，不能跨数据集计算专家与Agent同片轨迹一致性。后续应分别组织同片对照，且将分类正确性、导航覆盖和精确形态定位分开评价。

## 5. 最终六例结果与后续PEAN对照（2026-11-04）
六例推理已完成，均预测Malignant：C1/C2/C48为TP，C6/C8/C12为FP；TP=3、TN=0、FP=3、FN=0，无无效输出。accuracy=50%，Wilson95%CI=18.76%–81.24%，敏感度100%，特异度0%，balanced accuracy50%；排除旧C1后2/5正确。六例都在第一轮结束，只有C1追加一次40倍观察，其余各3次初始观察，总19次。这说明当前流程存在明显的阳性偏向与早期结束现象，不支持诊断区分能力或充分动态探索能力的结论。病灶定位是否正确尚未核验；阳性切片分类正确不等于导航命中病灶。
19个真实输入已在服务器逐一检查SHA、图像尺寸、WSI quickhash、ROI边界及acquisition对应关系，全部通过；输入联系图用于人工视觉核查。这是几何/文件校验，不是病理正确性验证。C1固定4ROI旧图vs新WSI回放完成，原baseline unchanged；第4次相同1024×1024level0范围由256px旧图变为512px原WSI新图，处理器252→504px。新图定位仍0/4满足坐标协议，不采用精确点。
交付分别为工作区outputs/PathAgent_六例WSI验证_20261104/PathAgent结果报告.html与outputs/PEAN_原规则适配_20261104/PEAN结果报告.html，禁止混合成一个报告。
PEAN范围审计发现三例全部有效帧被旧35000px门槛判为细览，首窗口覆盖整片矩形97.1%/89.4%/100%，存在过度归并。按用户确认，新增可选DynamicConfig分支：20倍完整短轴150px、长轴按每WSI宽高比；半径换算为axis_pixels/(2*max(anchor_zoom,current_zoom))，保留固定锚点并取较严格倍率范围，取消细览全窗口归并。默认原算法完全不变，冻结输出合同测试通过。
动态对照不应用旧大尺度几何压缩；空间版访问41/180/143，50FPS估计150ms版5/47/55，三例完整轴长167.27×150、200.17×150、258.33×150px。输出在outputs/PEAN_动态椭圆_20倍短轴150px_20261104/PEAN动态椭圆对照.html，原始坐标与筛除规则保持；时间仍未校准，细分程度待用户审阅，不自动继续调参。
