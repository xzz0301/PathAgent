## 1. PEAN原始记录和统一表

入口：`python -m experts.pean --raw-root <原始目录> --output <新输出目录>`。输出目录必须不存在，历史原始数据和结果不覆盖。

公开原件有150张NDPI、150个EPR和150个NDPA。逐文件SHA256表明EPR只有90份不同内容：30组黑色素瘤记录每组3份字节相同。90份记录均由EPR quickHash唯一匹配至实际NDPI，level-0尺寸全部一致；其余60张WSI没有对应的不同内容记录。脱敏医生字段相同不能证明只有一位实际阅片者。61475疾病命名冲突不阻止图像身份配对，但标签仍待核验。

EPR不是本批数据中的ZIP；实际以`EPRFILE`起始。适配器有界解析21、22两个版本，使用明确的小端字段和7-bit字符串长度，截断文件报错；不导入原训练入口，不使用原解析器筛选后的XY。

### 时间问题

150份文件头均为50FPS，但原时间戳中位间隔约0.166545，单位未确定，不能与20ms直接等同。官方EPR_file.xlsx注明“时间戳，单位很奇怪，建议对照FPS进行处理”。仓库issue #1也提出时间计算问题，核查时没有作者回复：<https://github.com/MasyerN/PEAN/issues/1>。

因此当前`time_ms`、`valid_support_ms`为空；不应用150ms阈值，也不以帧数乘20ms宣称获得真实停留。输出明确为**空间核查预览**。正式时间筛选须有可追溯的单位或同步证据后再启用。

### 空间筛选与区域归并

1. 依次检查原始字段、有效层级、屏幕边界、WSI边界和组织前景。原始表所有帧均保留，剔除只作用于后续分析。
2. NDPI缩略图存在橄榄色玻璃背景，仅靠亮度/饱和度会误判为组织。前景使用H&E相对于绿色的颜色差，结合局部暗组织、闭运算和孔洞填充；它不是细胞或肿瘤分割。保存掩膜与原始/有效落点对照供检查。
3. 低倍使用固定首个有效组织点为锚点的椭圆范围，探索参数为横向340μm、纵向590μm。转换到每张图的level-0像素，锚点不随样本移动。
4. 推导显示范围的短边≤1500μm时，启用局部区域观察归并：固定参考视野IoU≥0.65且平移≤参考宽高20%，或嵌套缩放覆盖≥0.85且原锚点仍在新视野。参数为探索设置，不是临床阈值。
5. 无效帧不贡献支持数量，间断保留为不同访问。访问包含帧范围、有效样本数和倍率序列；时间值仍为空。
6. 输出samples.csv、regions.csv、visits.csv、result.json、全片箭头图、坐标/前景核查图和HTML。R编号表示固定区域，访问顺序在右表逐次编号；图线是区域访问摘要，不是测得的连续眼跳。

静态NDPA含纳米坐标和非闭合线，不直接充当病灶掩膜，也不自动生成鼠标操作证据。本轮保留原始NDPA，尚未开展其坐标转换和语义核验。

## 2. PathAgent原流程与证据定位

主入口只新增`--capture-observations/--no-capture-observations`。默认保存实际送入Perceptor的PNG和SHA256，包含普通观察与放大裁剪；原诊断提示词和选区策略不改。结果表新增input_image_path、input_image_sha256。事件仍记录真实观察开始和完成。

离线入口：

```bash
python tools/ground_observations.py \
  --result <基线结果JSON> --checkpoint <服务器Patho-R1-7B> \
  --output <新定位输出目录> --wsi <对应原始WSI> \
  --device cuda:1 --max-observations 3 --mirror-probe
```

定位只读取问题和实际输入图像，不读取真值答案、专家落点或病灶标注。模型返回0到5个局部框和具体形态描述，指定主要证据；空结果必须给出原因。输出同时保留原始文本、提示词版本及哈希、token数量、耗时和解析状态。

默认框使用输入原图归一化坐标，严格检查有限值、边界、顺序、ID和主要证据引用。不自动把0–1000或像素坐标除以某个数字“修好”；不裁剪越界框，也不以中心点替代失败定位。另有显式`--coordinate-space input_pixels`协议：先保存模型实际输入画布，要求输出声明坐标单位及与画布一致的image_size，并核验处理器实际尺寸；仅在这些信息全部一致时按声明尺寸换算。过宽框保留并标记。可解析与病理正确是两个独立状态。

映射关系：`x_level0 = roi_x0 + x_norm * roi_width_level0`，y同理。使用实际图像尺寸和本次ROI几何，不使用模型处理器内部缩放后的张量尺寸。框中心仅作为展示点，原框及形态描述一并保留。

全片图画实际ROI范围和主要证据点之间的访问箭头；同一次ROI里的其他证据是并列发现，不编造时间顺序。缺定位的观察保留空缺，不连成完整成功轨迹。另导出逐ROI原图与框，检查模型是否只会返回泛化中心框。首个输入增加水平镜像探针供几何一致性分析，它不是临床正确性验证。

本轮实现**离线记录版**，没有把定位结果反馈导航。原有放大依然是既有patch裁剪，元数据明确保存此限制。真正WSI高分辨率读取、证据反馈导航和新的大规模对照在定位核查后推进，不宣称已经完成。

若Patho-R1定位失败，先分别检查输出格式、坐标约定、视觉位置对应及病理描述。替代候选仅作为独立定位模块测试，原诊断模型保留；不因JSON能够解析就宣布替换成功。

## 3. 验收和评价边界

测试覆盖原推理循环、回访/放大、输入图像像素保真、局部到全片坐标、空定位和坏JSON、越界不裁剪、EPR两个版本、截断文件、无效帧间断和有色玻璃背景。

首轮只做技术链路与案例核查，不给出诊断准确率或专家一致性的总体结论。C1、C6、C48均为开发案例。后续评价以有效观察和区域记录为依据，不以绘图压缩后的节点为样本；定位空间一致性不能替代病理证据语义正确性。

原服务器文件备份位于项目`.migration/evidence_20261104`。本轮不删除原始数据、不替换权重、不改变他人GPU进程，也不向外部模型服务上传病理图像。

## 4. 本轮实际结果（2026-11-04）

PEAN三例已在本地与6000D完成同一适配器运行。BCC `59979_0_BCC_0`：338帧、162个空间有效帧、16个固定区域、43次访问；SCC `59988_0_scc_0`：1060帧、956个有效帧、35个区域、112次访问；melanoma `62403_0_melanoma_0`：990帧、936个有效帧、44个区域、93次访问。它们是时间未校准的空间预览，不能称为150ms精简结果；区域与访问数量分开统计。

C1基线结果为`artifacts/c1_evidence_pilot_20261104/baseline/DX1_C1_3032b9e5.json`，使用服务器原始Qwen3-4B、Patho-R1-7B和PLIP，非空Quilt描述。4次观察包括3个初始ROI和1个裁剪观察，全部保存实际输入PNG。该案例预测与标签均为Malignant，不据此报告总体准确率。

Patho-R1首次定位试验只有1/3符合输出结构，但该框复制了提示词数值示例，已拒绝作为定位结果。去除数值示例后全4次观察均未满足当前完整协议；其中部分原始文本确有坐标，故不能据此断言模型绝对没有定位能力。两个试验目录均加入`AUDIT.json`，其蓝框不得用于专家轨迹对照。

独立候选为`Qwen/Qwen2.5-VL-7B-Instruct`，15个文件共16,595,961,266字节，通过ModelScope的Qwen发布者仓库获取，各权重SHA与HF镜像LFS元数据交叉核对。文件清单固定revision，SHA通过后才去掉`.incoming`后缀。服务器wrapper自动衔接下载、4次观察及首张镜像测试；候选尚未完成时不能报告定位成功。诊断与导航模型均不替换。

候选的15个文件已全部通过尺寸与SHA256复核。初次归一化接口0/4通过，原因是模型返回了像素坐标；没有自动猜测单位。显式像素协议重测4/4结构通过，共6个区域；普通图画布504×504、裁剪图252×252，均与实际处理器尺寸核实一致，原Perceptor输入保持512×512/256×256。输入快照、画布哈希、ROI几何和框到WSI映射均通过核查。

4个主要证据框覆盖原ROI的面积分别为78.8%、40.0%、100%、100%；3个触发面积>50%的探索性过宽提示。该提示用于可视化核查，不是临床接受阈值。首张镜像主框还原IoU=0.9687，但大框容易获得高重叠，不能证明细粒度定位正确。当前结果支持区域级提议的技术链路，尚不足以构成可信的具体细胞/关键组织观察轨迹，原始提议图必须与AUDIT同时查看。

新增像素协议坐标与错误画布测试后，本地与6000D19项回归测试均通过。最终统一入口位于工作区`outputs/PEAN_PathAgent_首轮验证_20261104/index.html`；逐帧一致性核对、候选状态和未完成项见同目录报告。PEAN三例与CAMELYON16 C1不是同片对照，这里分别验证数据适配与Agent记录能力。下一步待讨论的优先项是：PEAN时间校准、真正WSI高分辨率读取、较小形态区域的定位核查，以及已有专家轨迹与同片Agent区域的评价；本轮没有开展全量实验或训练。
